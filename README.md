## Installation

প্রথমে repository clone করুন:

```bash
git clone https://github.com/itsdevelopershakil/PH-practice.git
cd PH-practice
```

এরপর যে module-টি run করতে চান, সেই module folder-এর README দেখুন। উদাহরণ:

```bash
cd module-7
```
